# 📋 INFORME TÉCNICO - FASE 1: PROTOTIPO
## *Rutas del Alma: El Juego*
**Documento para Desarrollo · Versión 1.0**  
**Fecha:** Noviembre 2026  
**Alcance:** Prototipo web jugable (Nivel 1 - "El Valle y el Jardín de la Mente")

---

## 1. OBJETIVO DE LA FASE

Desarrollar un **prototipo funcional en HTML5** que valide las mecánicas núcleo del juego en un entorno controlado, utilizando los assets visuales existentes (ilustraciones estáticas en pixel-art) y demostrando la viabilidad técnica de la propuesta.

### Criterios de Éxito
- ✅ Juego ejecutable en navegador (Chrome, Firefox, Safari) sin instalación
- ✅ Tiempo de carga inicial < 5 segundos en conexión 4G
- ✅ 60 FPS estables en dispositivo de gama media (2020+)
- ✅ Un tester externo completa el nivel sin asistencia en < 15 minutos
- ✅ Las tres mecánicas principales funcionan: movimiento, lámparas y sombreros

---

## 2. ESPECIFICACIONES TÉCNICAS

### 2.1 Stack Tecnológico Recomendado

| Capa | Tecnología | Justificación |
|------|-----------|---------------|
| **Motor** | Godot 4.2 LTS | Exportación WebGL ligera, excelente soporte 2D, GDScript rápido de prototipar |
| **Alternativa** | Phaser 3 + TypeScript | Si el peso de Godot WebAssembly excede 10MB, cambiar a JS puro |
| **Lenguaje** | GDScript 2.0 | Curva de aprendizaje suave, tipado opcional para prototipado rápido |
| **Diálogos** | JSON propio + Ink (fase 2) | Prototipo: JSON simple. Producción: migrar a Ink para ramificación |
| **Audio** | Howler.js + archivos OGG | Ligero, compatible web, compresión eficiente |
| **Guardado** | localStorage (prototipo) | Sin backend. Producción: Firebase/Supabase |
| **Hosting** | GitHub Pages / Itch.io | Gratuito, HTTPS, CDN global |

### 2.2 Requisitos de Rendimiento

**Objetivos medibles:**
- **Peso total del build:** < 15 MB (comprimido Brotli)
- **Memoria RAM:** < 256 MB en ejecución
- **CPU:** < 30% en móvil gama media
- **Primera interacción:** < 2 segundos tras carga

**Optimizaciones obligatorias:**
- Compresión de texturas: PNG-8 indexado para sprites, WebP para fondos
- Atlas de texturas único (máx. 2048x2048)
- Lazy loading de niveles (solo cargar Nivel 1)
- Object pooling para partículas y proyectiles
- Desactivar VSync en móvil si FPS < 60

## 4. MECÁNICAS A IMPLEMENTAR

### 4.1 Sistema de Movimiento (Prioridad: ALTA)

**Especificaciones técnicas:**

```gdscript
# player/Player.gd
extends CharacterBody2D

@export var speed: float = 200.0
@export var jump_velocity: float = -400.0
@export var gravity: float = 980.0
@export var coyote_time: float = 0.1  # 100ms
@export var jump_buffer: float = 0.1  # 100ms

var can_jump: bool = false
var jump_pressed: bool = false
var coyote_timer: float = 0.0

func _physics_process(delta):
    # Gravedad
    if not is_on_floor():
        velocity.y += gravity * delta
        coyote_timer -= delta
    else:
        can_jump = true
        coyote_timer = coyote_time
    
    # Buffer de salto
    if Input.is_action_just_pressed("jump"):
        jump_pressed = true
        jump_buffer_timer = jump_buffer
    
    # Salto con coyote time
    if jump_pressed and (can_jump or coyote_timer > 0) and velocity.y < 0:
        velocity.y = jump_velocity
        jump_pressed = false
        can_jump = false
        emit_signal("jumped")
    
    # Movimiento horizontal
    var direction = Input.get_axis("left", "right")
    if direction:
        velocity.x = direction * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed * 0.2)
    
    move_and_slide()
```

**Controles:**
- **PC:** WASD / Flechas + Ratón (apuntar lámpara)
- **Móvil:** Joystick virtual (izquierda) + Botones táctiles (derecha)

**Métricas de validación:**
- Salto preciso en plataformas de 32px de ancho
- Caída sin daño: teletransporte a último checkpoint
- Velocidad máxima: 200px/segundo

### 4.2 Sistema de Lámparas (Prioridad: ALTA)

**Lámpara de Liam (Acción):**
- Cono de luz de 90° apuntable con ratón/dedo
- Medidor de energía: 100 puntos, consume 10/segundo
- Recarga: 20/segundo cuando no está activa
- Revela plataformas ocultas (cambia collision layer)
- Activa mecanismos (señal `mechanism_activated`)

```gdscript
# player/Lamp.gd
extends Node2D

@export var max_energy: float = 100.0
@export var drain_rate: float = 10.0
@export var recharge_rate: float = 20.0
@export var light_cone_angle: float = 90.0

var current_energy: float = max_energy
var is_active: bool = false
var light_polygon: Polygon2D

func _process(delta):
    if is_active and current_energy > 0:
        current_energy -= drain_rate * delta
        update_light_cone()
    elif not is_active and current_energy < max_energy:
        current_energy += recharge_rate * delta
    
    if current_energy <= 0:
        is_active = false
        emit_signal("lamp_depleted")

func activate():
    if current_energy > 0:
        is_active = true
        emit_signal("lamp_activated")

func deactivate():
    is_active = false
    emit_signal("lamp_deactivated")
```

**Lámpara de Elara (Narrativa):**
- Raycast 2D para detectar sombras en línea de visión
- Al hacer clic: abre sistema de diálogo
- Diálogo de 3 turnos con 3 opciones por turno
- Sistema de "escucha correcta": reflejar > preguntar > aconsejar

```gdscript
# world/Shadow.gd
extends CharacterBody2D

@export var shadow_id: String
@export var dialogue_tree: Dictionary
var is_revealed: bool = false
var is_dissolved: bool = false

func interact_with_lamp():
    is_revealed = true
    DialogueSystem.start_dialogue(dialogue_tree)
    connect("dialogue_completed", _on_dialogue_completed)

func _on_dialogue_completed(success: bool):
    if success:
        dissolve_animation.play()
        is_dissolved = true
        emit_signal("shadow_dissolved", shadow_id)
        # Drop collectible
        var flower = Flower.new()
        flower.position = position
        get_parent().add_child(flower)
```

### 4.3 Sistema de Sombreros (Prioridad: MEDIA)

**Implementación:**
- Rueda radial (8 posiciones) activable con tecla Q / botón UI
- Solo 2 sombreros en prototipo: Blanco y Rojo
- Cooldown: 0.5 segundos entre cambios
- Efecto visual: Filtro de color en CanvasLayer + partícula

```gdscript
# player/HatSystem.gd
extends Node

enum HatType { NONE, WHITE, RED }
var current_hat: HatType = HatType.NONE
var hat_cooldown: float = 0.0
const COOLDOWN_TIME: float = 0.5

signal hat_changed(hat_type: HatType)

func _process(delta):
    if hat_cooldown > 0:
        hat_cooldown -= delta

func change_hat(new_hat: HatType):
    if hat_cooldown > 0 and new_hat == current_hat:
        return  # Toggle off if same hat
    
    current_hat = new_hat
    hat_cooldown = COOLDOWN_TIME
    emit_signal("hat_changed", current_hat)
    
    # Apply visual effect
    var color_filter = CanvasModulate.new()
    match new_hat:
        HatType.WHITE:
            color_filter.color = Color(1, 1, 1, 0.3)  # Bright
        HatType.RED:
            color_filter.color = Color(1, 0, 0, 0.2)  # Warm
    get_tree().current_scene.add_child(color_filter)

# White Hat: Reveal hidden clues
func reveal_facts():
    if current_hat == HatType.WHITE:
        var clues = get_tree().get_nodes_in_group("hidden_clues")
        for clue in clues:
            clue.visible = true
            clue.modulate.a = 1.0

# Red Hat: Enable emotional dialogues
func enable_emotional_dialogue():
    if current_hat == HatType.RED:
        DialogueSystem.enable_mode("emotional")
```

### 4.4 Sistema de Malezas y Flores (Prioridad: MEDIA)

**Mecánica:**
- Malezas: Áreas estáticas con colisión, interacción con tecla E
- Flores: Coleccionables, +10 puntos de "Jardín Interior"
- Animación: 0.5s para arrancar, 0.5s para sembrar

```gdscript
# world/Weed.gd
extends Area2D

@export var weed_type: String  # "fear", "doubt", "resentment"
var is_removed: bool = false

func _on_body_entered(body):
    if body.is_in_group("player") and Input.is_action_just_pressed("interact"):
        start_removal_animation()

func start_removal_animation():
    var tween = create_tween()
    tween.tween_property(self, "modulate:a", 0.0, 0.5)
    tween.tween_callback(_on_removed)

func _on_removed():
    is_removed = true
    queue_free()
    emit_signal("weed_removed", weed_type)
    GameState.add_flower()
```

   - Malezas: 3 tipos (miedo, duda, resentimiento)

4. **UI:**
   - Joystick virtual (base + knob)
   - Botones: salto, lámpara, interacción, sombreros
   - Barra de energía de lámpara
   - Contador de flores (0/12)
   - Caja de diálogo
