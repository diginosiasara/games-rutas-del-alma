# 📄 INFORME TÉCNICO — SISTEMA DE DIÁLOGO DE AIDES
## *Rutas del Alma: El Juego* — Ramificación, Consecuencias y Gestión de Tareas
**Base narrativa:** Capítulo 1 (El Jardín de la Mente) y Capítulo 4 (Las Llaves del Pensamiento)  
**Objetivo:** Crear el sistema de diálogo interactivo entre **Aides y el Jugador (Liam/Elara)**. A diferencia de Callum (que actúa como mentor), Aides es un **espejo del estado interno del jugador**. Sus diálogos reflejan la salud del jardín, su propio nivel de fatiga y la calidad de la "escucha" del jugador.

---

## 1. VARIABLES DE ESTADO AFECTADAS POR AIDES

| Variable | Descripción | Efecto en el Gameplay |
| :--- | :--- | :--- |
| **`aides_confianza`** | Qué tanto confía Aides en su propio criterio. | Alta: trabaja más rápido y desbloquea acciones avanzadas. Baja: duda, comete errores (riega mal). |
| **`aides_fatiga`** | Cansancio físico y emocional. | >80%: Aides se niega a trabajar o abandona el jardín. <20%: Entra en estado "Flow" (crecimiento x2). |
| **`vinculo_jugador`** | Nivel de empatía del jugador hacia Aides. | Determina si Aides acepta "pedidos" complejos (ej. cuidar el jardín en bucle) o si exige descansar. |
| **`jardin_salud`** | Porcentaje de salud del ecosistema. | Aides comenta este estado en sus diálogos. |

*   **Si elige A (Rojo):** Aides sonríe. *"Tiene miedo. Como yo. Pero al nombrarlo, ya no me asusta."* (Desbloquea diálogo de empatía).
*   **Si elige B (Blanco):** Aides asiente. *"La luz muestra el camino, pero mis manos hacen el trabajo. Gracias."* (Refuerza el trabajo en equipo).
*   **Si elige C (Orden):** Aides baja la cabeza. *"Sí... como tú digas."* (Aides entra en modo "Obediencia": trabaja más lento y no genera flores raras).

## 5. ESPECIFICACIONES TÉCNICAS PARA EL DESARROLLADOR

### 5.1 Sistema de "Memoria Emocional" de Aides
Aides no es un NPC de una sola línea. Su diálogo inicial cambia según el historial del jugador:
*   **Si el jugador ha sido empático (muchos Pétalos):** Aides saluda con frases como *"El jardín respira mejor hoy"* o *"Callum y yo estábamos hablando de ti"*.
*   **Si el jugador ha sido autoritario (muchos Granos, poca empatía):** Aides saluda con frases cortas: *"¿Qué hay que hacer?"* o *"El jardín está... como está"*.

### 5.2 Integración con el Bucle de Trabajo (FSM)
Cuando el jugador elige la **Opción A del Diálogo 2** (Pedir cuidado en bucle), se activa un temporizador en el código:
```javascript
// Pseudocódigo para el bucle de Aides
function loopAides() {
  if (aides_state === 'TRABAJANDO') {
    aides_fatiga += 5;
    if (aides_fatiga > 80) {
      changeState('VOLVIENDO_A_CASA');
    }
  } else if (aides_state === 'DESCANSANDO') {
    aides_fatiga -= 10;
    if (aides_fatiga < 30 && jardin_salud < 80) {
      changeState('YENDO_AL_JARDIN');
    }
  }
}
```

### 5.3 Reacción a las Luces (Zarzas)
Si el jugador usa la lámpara mientras habla con Aides cerca de una zarza:
*   **Luz de Liam:** Aides dice: *"Ahí está. La raíz brilla. Ya sé por dónde tirar."* (Reduce el tiempo de la animación de arranque a la mitad).
*   **Luz de Elara:** Aides dice: *"Pobre... solo está asustada. No es mala, solo duele."* (La zarza no se arranca, pero se convierte en "Tierra fértil" instantáneamente, ahorrando trabajo).

---

## 6. CRITERIOS DE ACEPTACIÓN (DEFINITION OF DONE)

*   ✅ Aides tiene al menos 3 reacciones distintas según el sombrero que lleve el jugador.
*   ✅ El jugador puede activar el "Modo Autonomía" (bucle) de Aides desde la cabaña.
*   ✅ Si el jugador culpa a Aides en la crisis, ella se bloquea (huelga emocional) y el jardín no se limpia solo.
*   ✅ Las luces de Liam y Elara modifican las opciones de diálogo y la eficiencia de Aides en tiempo real.
*   ✅ El guardado local recuerda el nivel de `vinculo_jugador` y `aides_confianza`.
