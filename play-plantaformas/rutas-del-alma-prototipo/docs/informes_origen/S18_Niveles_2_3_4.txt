## 3. ESPECIFICACIONES TÉCNICAS DE INTEGRACIÓN

### 3.1 Fondos vs. Sprites Interactivos

**Regla crítica:** Los assets marcados como "fondo" (TM-01, TM-02, TM-03, PS-01, PS-02, PS-03, CR-01, CR-02, CA-01) **no son sprites interactivos**. Son ilustraciones grandes (128x128 px o más) que deben usarse como:
- **Fondos de parallax** (capa lejana, media, cercana)
- **Pantallas de transición** entre zonas
- **Escenarios de cutscenes**

**Implementación:**
```javascript
// Ejemplo para el Templo Exterior
const bg_temple = {
  image: 'bg_temple_exterior_1f.png',
  type: 'parallax',
  layers: [
    { speed: 0.2, y: 0 },      // Montañas lejanas
    { speed: 0.5, y: 50 },     // Colina del templo
    { speed: 1.0, y: 100 }     // Templo principal
  ]
};
```

## 7. RIESGOS Y MITIGACIÓN

| Riesgo | Impacto | Mitigación |
| :--- | :--- | :--- |
| Fondos grandes (128x128 px) ralentizan el render | Rendimiento | Usar como parallax estático, no como sprites animados |
| Custodias interpretadas como enemigas | Narrativo | Documentar en código: `isHostile = false` |
| MA-03 duplicado causa conflicto de nombres | Técnico | Renombrar a MA-04 antes de integrar |
| Animaciones de NPCs estáticos se sienten "rígidas" | Visual | Ajustar parámetros de respiración/balanceo para cada pose |
| Peso total del build > 4 MB | Rendimiento | Comprimir PNG a PNG-8 indexado; usar WebP si el motor lo soporta |
