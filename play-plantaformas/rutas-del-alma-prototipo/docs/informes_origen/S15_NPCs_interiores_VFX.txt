## 3. DESVIACIONES DE DIRECCIÓN DE ARTE (BLOQUEANTES VISUALES)

### 3.1 🔴 Aura de Liam es rosa, no dorada
- El brief del Sprint 14 pedía: *"resplandor dorado que pulsa y se expande"*.
- La hoja muestra **L-01 en rosa/magenta con centro amarillo**, idéntico en forma a L-02 (Elara).
- **Consecuencia:** rompe el lenguaje cromático del juego (dorado = Liam/hechos, violeta = Elara/emoción). El jugador no podrá distinguir a quién pertenece el efecto.
- **Corrección solicitada al artista:** L-01 debe ser **dorado puro** (`#FFD700` / `#F4D03F`), con rayos solares, **sin halo rosa**.

### 3.2 🟡 L-01 y L-02 son morfológicamente idénticas
- Ambas son "anillo con centro". Solo cambia el color del núcleo.
- **Corrección:** diferenciar por **forma**, no solo por color (accesibilidad daltónica, Sprint 8):
  - **Liam (dorado):** rayos rectos, sol naciente, borde duro.
  - **Elara (violeta):** espirales suaves, neblina ondulante, borde difuso.

### 3.3 🟡 Dimensiones de los VFX
- El aura de Liam ocupa visualmente más de 32x32 px en la hoja.
- **Corrección:** recortar a **bounding box 32x32** (o 48x48 si el artista lo justifica) y verificar que el anchor esté en el centro exacto.

## 4. ESPECIFICACIONES TÉCNICAS DE INTEGRACIÓN

### 4.1 NPCs — Animación procedural sobre 1 frame
Al igual que los protagonistas (Sprint 13), Tomás y el Consejero son estáticos. Aplicar:

| Personaje | Pose | Procedural |
| :--- | :--- | :--- |
| **Tomás** | T-01 Desanimado | Cabeca inclinada fija + respiración lenta (Y ±1 px, 3 s) |
| **Tomás** | T-02 Dolor | Shake sutil de hombros (X ±2 px, 0.4 s) + vapor de "suspiro" (E-02) |
| **Tomás** | T-03 Esperanzado | Respiración normal + brillo cálido en la maceta |
| **Tomás** | T-04 Escuchando | Asentimiento lento (rotación ±2°, 2 s) |
| **Conejo** | C-01 Idle | Parpadeo (swap de ojos, 2 frames derivados) + orejas (±3°) |
| **Conejo** | C-02 Run | Tira horizontal de 3 frames, 12 FPS |
| **Conejo** | C-03 Señalando | Pata fija + oreja que se mueve |
| **Consejero** | S-01 Idle | Barba/vestido con viento (rotación ±2°) |
| **Consejero** | S-02 Ofreciendo | Sombrero blanco con "pop" de escala 1.0→1.05→1.0 |
| **Consejero** | S-03 Explicando | Brazos fijos + destello L-03 ocasional |

### 4.2 Interiores — Autotile y orden de capas
```
Layer 0: I-01 suelo madera (autotile, 2 variantes)
Layer 1: I-02 chimenea (fondo) + I-04 estantería + I-05 ventana
Layer 2: I-03 mesa té + I-06 banco (PENDIENTE) + I-07 puerta (PENDIENTE)
Layer 3: sprites de Callum (CA-03 Seated) y Aides (AI-08 Descanso)
Layer 4: VFX E-02 vapor té (sobre las tazas)
```
**Regla:** el vapor (E-02) se emite desde la posición de las tazas de I-03, no desde el personaje.

### 4.3 VFX — Object Pool y blending
- **Auras (L-01, L-02):** `globalCompositeOperation = 'lighter'`, alpha oscilante 0.6–1.0, periodo 1 s.
- **Destellos (L-03, G-03):** `lighter`, burst único de 3-4 frames, luego destruir (reciclar en pool).
- **Partículas (L-04, E-04):** pool de 24 máximas, movimiento con `sin(t)` para flotación.
- **Fuego/agua (E-01, E-03, G-02):** loop de frames, 8-12 FPS.
- **Ruptura (G-01):** burst único, 0.4 s, con shake de cámara 2 px.
